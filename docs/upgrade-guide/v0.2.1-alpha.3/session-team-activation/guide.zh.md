# 会话级团队模式开启

[English](guide.md) | 中文

## 变更

智能体团队 profile 的新建根对话默认普通模式。用户执行 `/team` 后，为当前对话永久开启原有官方团队能力。没有开启状态记录的已有对话保持团队行为。开启后的团队角色、工具和协作机制不变。

新会话记录必需的 `team/mode` 事件。不识别该事件的旧版本会拒绝读取这些日志，不会静默开启团队。更新后的版本仍可读取已有日志。

## 迁移

1. 打开使用会话级团队模式的新对话前，先升级应用；旧应用拒绝读取时保留日志。
2. 在需要团队协作的交互式对话中，等待空闲后执行 `/team`。重新打开对话保持开启状态，新建对话仍默认普通模式。
3. 需要立即使用团队能力的 headless 组合，可在 profile patch 的 `agent-team` 条目上设置 `defaultMode: team`。该设置只影响新会话。
4. 确认普通对话没有团队页头入口，执行 `/team` 后出现官方入口与工具。
