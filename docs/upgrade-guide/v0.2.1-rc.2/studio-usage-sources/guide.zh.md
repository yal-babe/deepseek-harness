# Studio 会话用量归属

[English](guide.md) | 中文

## 变更

Studio 将选中会话导出为 `dsh-session-2`，增加原始 Session 来源区间，用于跨设备和分支的 Token 统计。旧版 Studio 客户端会拒绝这些载荷。新版仍读取 `dsh-session-1`；祖先缺失时标记统计不完整，不按内容合并互不相关的调用。官方 Harness Session 日志和 Agent 执行不变。

个人中心按提供方和模型分组，独立保留精确总量与缓存明细，并重建浏览器用量缓存。现有模型行 API 消费方需要同时读取 `provider` 与 `model`。云端活动响应增加缓存写入合计和可选的缺失数据标记；这些是已记录用量，不是提供方账单。单会话行保留继承消耗以匹配聊天，全局总量则对继承请求去重，因此不能将展示的 Session 行相加。

## 迁移

1. 在导出新同步会话之前更新所有 Studio 设备。该载荷变更无需迁移云服务数据库。
2. 重新导出旧分支会话时，保留原始父会话或其下载历史，以便恢复来源区间，不上传未选中会话正文。缺失的历史祖先不能仅凭内容重建。
3. 打开个人中心重建用量快照。确认刷新不改变日期和总量、不同提供方独立分组，且同时同步祖先和后代不会重复计入继承调用。不要为清理浏览器缓存而删除 Session 日志或云端历史。
