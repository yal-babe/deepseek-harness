# Agent Note: 大肥鱼媒体与设备级玩耍行为

Status: implemented

[English](2026-10-17-dafeiyu-motion.md) | 中文

## 问题

每个状态内嵌六帧无法表达原角色的完整互动；将全部 3,444 帧导入客户端入口又会增加下载和图片解码成本。面板展开时也需要保持用户选定的角色位置。

## 决策

Host 通过 `pet.pack()` 提供允许列表中的内置媒体，并负责可卸载的 `/pet-motion` 路由。16 段透明 VP9 视频保留导入的源帧，四组生成图集为每种互动提供八个姿态；视频和图集仅在选中时加载。帧渲染器继续用于回退和开发包。

Client 负责待机计时、点击冷却、特效与设备级移动偏好。Host 任务状态打断装饰行为，拖拽与落地保留最新任务状态；角色坐标独立于面板。Desktop 负责原生窗口移动并校验渲染进程的布尔型自主移动请求，悬停、隐藏、拖动及卸载均会取消移动。

[Phase 0 结论](../../proposed/feature/2026-10-17-studio-pet-phase0-findings.zh.md) 仍适用于审批竞争和认证连接；本决策扩展媒体与互动，保留这些职责归属。

## 考虑的替代方案

内嵌全部帧会增加入口体积与图片解码占用；新增原生 Helper 会重复现有 Electron 窗口生命周期；外部媒体 URL 会给内置互动增加网络依赖。随包提供且按需加载的媒体复用 Chromium 解码与应用已有的认证 HTTP 传输。

## 后果

内置媒体增加随包资源，并要求 HTTP 支持字节范围响应。四组生成动作各有八个关键姿态，没有插帧至源视频的帧率；开发包保留现有帧格式。设备级玩耍不改变提示词、智能体角色、模型配置、云同步或审批决定。

## 验证

真实 Loader 组合测试覆盖媒体、范围请求、非法路径和路由卸载；Client 测试覆盖待机休息计时、任务打断、拖拽落地、减少动态、图集结束与定时器清理；Desktop 测试覆盖有界自主移动及取消。Chromium 冒烟运行验证了透明解码、Web 拖动、新动作菜单和主题渲染。Windows 与 macOS 的原生 Electron 行为仍需平台验证。
