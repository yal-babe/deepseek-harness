# Agent Note: 会话级团队模式开启

Status: implemented

[English](2026-10-15-session-team-activation.md) | 中文

## Problem

桌面团队组合包在创建成员前就为所有新对话指定 Lead 身份。用户需要普通对话，并能显式开始协作，同时保留官方团队行为。

## Decision

profile 为新建根对话选择普通模式。用户空闲时执行 `/team`，单次开启原有团队能力。服务记录必需的 `team/mode` 事件，团队投影负责开启状态，成员资格与会话作用域工具安装使用该状态。没有该事件的已有日志保留隐式团队；重新打开普通日志不会开启团队。

## Alternatives considered

profile 级开关会影响其他对话。只移除页头或身份仍保留团队工具与权限。可忽略记录会让旧读取方把普通对话重建为团队，因此开启状态使用必需事件，未知事件拒绝机制会保留日志。

## Consequences

开启后的官方身份、提示词、工具与委派保持原样。新的普通会话需要能识别开启记录的读取方。单向切换避免为退出团队而中断成员或删除共享任务。headless 用户可在自己的 profile patch 中显式选择服务的团队默认模式。
