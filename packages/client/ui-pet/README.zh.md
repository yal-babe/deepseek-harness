# @deepseek-ai/dsh-client-ui-pet

[English](README.md) | 中文

## 概述

内置桌宠的浏览器端。它镜像 Host [`pet`](../../pet/pet/README.zh.md) 快照，渲染一个带气泡的小型动画角色。气泡显示焦点会话、待审批项，以及可拖入文件的快速提问框。Web 上角色位于 `shell.overlay`。在 Desktop 桌宠窗口（`?dsh-pet-window=1`）中，插件遮蔽 `root`，整个透明文档就是桌宠。

## 使用本包

web-app bundle 将本插件与 Host `pet` 模块一同挂载。打开任意 Web 页面，右下角即显示角色；拖动可重新摆放，位置保存在本设备。设备级设置“甩动抛出”（默认开启，减少动态时关闭）开启时，角色以弹簧方式跟随指针，快速拖动后松手会把它抛出：受重力下落、在视口边缘反弹、在底部减速，并保存落点；在空中按住可接住它。物理效果移植自上游 dsh-pet（见 `NOTICE`）。在 URL 后加 `?dsh-pet-window=1` 可在浏览器中预览桌宠窗口界面。Desktop 在该 URL 上打开一个独立的透明置顶窗口，此时 Desktop 主窗口不再显示页内角色。在桌宠窗口中，拖动角色超过 4 px 会移动窗口而不是打开气泡；Desktop 桥接支持时，甩动会以同一套物理把窗口抛过各个显示器；展开面板或菜单时整个窗口保持在屏幕内；Desktop 托盘也可以通过同一个 Host 设置显示或隐藏桌宠。`CommandOrControl+Shift+Space` 可在任何地方展开或收起快速提问，并在桌宠被隐藏后重新显示它。

右键点击角色打开菜单：快速提问、打开主窗口（仅 Desktop）、开关系统通知、勿扰 1 小时、隐藏桌宠。按 Escape 关闭菜单。"打开主窗口"会把 Desktop 主窗口切到前台，并打开桌宠当前展示的会话；审批卡片与提问卡片上的"打开主窗口"按钮打开该卡片所属的会话。Web 上没有独立窗口，这些卡片按钮直接在当前页面打开该会话。

系统通知默认关闭，需要从菜单开启，开启时会向浏览器或 Desktop 申请权限。开启后，出现新的审批请求、会话完成或出错时桌宠会发通知，但仅在你没有看着桌宠所在文档、且不在勿扰时段内时发送。点击通知会把应用切到前台并打开对应的会话。两项设置按设备保存在 `localStorage`（`dsh-pet:preferences`），不同步；Desktop 桌宠窗口与主窗口通过 `storage` 事件同步彼此的修改。

设置面板中有 **大肥鱼** 页面（`settings.section`，id `pet`），在 Web 和 Desktop 主窗口中提供，条件是挂载了 ui-settings 且 Host 提供 `pet` 条目。它通过 `configForms` 编辑 Host [`pet`](../../pet/pet/README.zh.md) 字段：显示桌宠、三个通知类别（新的审批请求、任务完成、任务出错），以及"限制可在桌宠中审批的工具"和工具列表（默认关闭，桌宠可以审批全部工具）。该页面还包含按设备保存的系统通知开关，并说明桌宠当前运行在 Desktop 窗口还是页面内。

审批卡片出现后两个按钮会禁用 800 ms，回车从不批准。设置限制的工具的审批不显示按钮，而是说明限制并提供"打开主窗口"。在桌宠中决定与在主窗口中决定回答的是同一个 Host 请求；先到的回答生效，另一处界面关闭卡片。

当 Agent 提问（`ask_user_question`）且没有待审批项时，气泡显示提问卡片。只提供单选选项的问题可以在桌宠中回答，同样有 800 ms 延迟：单个问题点一次即提交，多个问题则每题选一项后点"提交回答"。自由文本与多选问题显示一个打开主窗口的按钮。

内置动作从 Host 按需加载，内嵌的小帧集用于失败回退。仅空闲时显示的“动作…”菜单项先列出宠物包的分类（内置包为小动作、玩耍、互动、吃什么和移动），再列出分类中的片段，每一级都有“返回”；具名动作使用词典文案，三个点击回应等仅存在于宠物包的片段使用包内 zh/en 名称。没有分类的宠物包直接列出动作。可选的部位点击分别触发头部、身体和尾巴动作，默认单击仍打开面板。设备级设置控制安静／标准／活泼待机间隔、自主移动（默认关闭）、特效和减少动态；工作、提问、审批、拖动及展开面板优先于空闲玩耍。设备偏好支持名称（默认“大肥鱼”）、50%～200% 大小、空闲／休息／娱乐状态，以及允许自主播放的动作。宠物包的 `motion.json` 列出分类时，自主动画链先在当前生活状态可用的分类中按权重抽取分类，再从中选出与上一段不同的片段；内置包的小动作分类（伸懒腰、打哈欠、东张西望和发呆碎碎念）用于空闲，玩耍分类（弹跳和气鼓鼓两个点击回应以及原地奔跑）用于娱乐。没有分类的宠物包使用两组固定的具名动作列表（空闲为伸懒腰、打哈欠、发呆、观察和整理仪容；娱乐为吐泡泡、庆祝、追逐泡泡、玩球和尾巴转圈），并只保留宠物包具备的片段。属于具名动作的片段遵守允许自主播放的动作列表。标记为转身的片段（如东张西望）播放后角色朝向反转，之后的片段随之镜像，标记为不可镜像的除外。任务状态自动覆盖生活状态，结束后恢复；休息从宠物包具备的第一组片段播放入睡、持续睡眠和醒来分段：先是 AI 视频槽位 `pillow_enter`／`pillow_loop`／`pillow_wake` 与 `sleep_enter`／`sleep_loop`／`sleep_wake`，再是内置包附带的上游小憩 `doze_enter`／`doze_loop`／`doze_wake`，醒来时随机平静醒来或被惊醒（`doze_startle`）；都没有的宠物包先打一次哈欠，再循环 `idle`，醒来时伸懒腰。自主滑行播放起步、定向游动和停下分段（`swim_start`、`swim_loop`、`swim_stop`），Web 和桌面端分别更新页面坐标与原生窗口；仅帧图宠物包和带 `swim_loop` 的动作包会滑行，因此内置包只靠行走片段移动。宠物包的 `motion.json` 带有动画链权重时（内置包沿用上游的 idle 10、turn 5、move 5），每轮空闲先在分类、转身片段和行走片段之间选择；行走需要开启自主移动且朝向前方有足够空间，空间不足时改为转身，未开启时回到分类。行走片段按媒体播放位置读取测得的位移来移动页面坐标或 Desktop 窗口，使脚步不打滑；镜像片段反向行走，拖动、任务或页面隐藏会结束行走并保存位置。平铺动作列表和允许自主播放的动作设置只显示宠物包具备对应片段的具名动作；内置包为摸摸头、戳一戳、点点尾巴、吃 Token、伸个懒腰和打个哈欠。其余十四项（吐泡泡、睡觉、蹭手、庆祝、发呆望天、好奇观察、悠闲游动、整理仪容、追逐泡泡、玩小皮球、尾巴转圈、翻书阅读、托腮思考和抱枕酣睡）是预留槽位，由同名的 AI 视频片段填入，见[AI 视频片段指南](../../pet/pet/tools/AI_VIDEO_CLIPS.zh.md)。请求缺失的片段时播放替代片段：庆祝播放 `success`，蹭手播放摸头，玩耍类动作播放 `click_bounce`（尾巴转圈为 `turn_run`），发呆望天播放发呆碎碎念，休息类播放 `idle_yawn`，托腮思考播放深度思考，翻书阅读播放 `thinking`。图集播放仍保留给自带图集的宠物包：它跟随浏览器动画帧调度，等待图片加载，并在分段切换时复用已加载图集。思考阶段在可用的思考、灵光一闪、阅读和深度思考片段间轮换，不增加模型请求。上游替身片段（发呆碎碎念替发呆望天，深度思考替托腮思考）在宠物包具备该槽位的 AI 视频片段后，退出自主动作和思考轮换。Host 的时刻进入新的时段或节日阶段时（以及启动后一次），空闲且未展开面板或菜单的桌宠会在气泡中显示宠物包本地台词表里的一句问候或节日台词，持续八秒；忙碌时发生的变化会被跳过，也不请求模型。

宠物包事件档位与点击回应：`motion.json` 声明 `events.workStatus` 时，任务状态按其档位播放（思考、工作、命令与测试的结果档、等待、成功、出错），搜索仍用自己的片段；内置包声明的正是原先播放的片段。声明 `clicks` 时，可交互的单击按头部、身体、尾巴（上 35%、中部、下 28%）从该部位的片段中选一个与上次不同的播放；内置包的身体点击回应戳一戳、弹跳或气鼓鼓，头部点击回应摸头或害羞惊讶。声明 `events.balance` 时，空闲桌宠的菜单提供“查看余额”：桌宠请求 `pet.panel.metrics` 的提供方，按已用比例最高的一条读数播放对应档位（每 20% 一档共六档，最后一档仅在 100% 时）并说出其文案，15 秒内没有读数则说暂时查不到余额。余额从不自动查询。除时刻台词外，任务结束时桌宠说宠物包本地的 `turn.success` 或 `turn.error` 台词，审批或提问等待时说 `approval.waiting` 台词（面板收起时显示），空闲满 20 分钟后说一次 `idle.long` 台词，宠物包声明 `events.whisper` 时同时播放悄悄话片段（内置包声明了发呆碎碎念）。设备级“说本地台词”开关可关闭全部台词。允许自主播放的列表也包含动画链可能抽到的、仅存在于宠物包的片段（分类成员、转身和行走），按包内名称列出。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

- `PetStore` 通过 `ctx.remote.$stream` 消费 `pet.watch()`；载体断开或终止性失败会让角色显示 `DISCONNECTED`，直到下一帧到来。
- 审批不经 Host 决定。每个 Client 本来就用 ui-approval 的 `PendingApproval` 回答转发来的 `approval/request` waterfall。桌宠从 `uiSession.sessionStatus` 读取这些对象，按会话与工具调用与 Host 待审批项匹配，并通过 `PetApprovalBridge` 回答；它会拒绝同一界面的第二次提交。Gateway 以第一个结果结束 waterfall 并取消其他 Client，因此主窗口与桌宠窗口不可能都做出决定。
- 提问走同一路径：ui-user-questions 把每个请求作为 `PendingQuestion` 发布到 `uiSession.sessionStatus`，`PetQuestionBridge` 对该对象只回答一次。已结束的回顾卡片与计划评审会被跳过。
- 通知比较 Host 的相邻两帧（`diffNotices`）；连接后的第一帧从不通知，子 Agent 会话会被跳过。Desktop 中只有桌宠窗口运行 ui-pet，所以每次变化只通知一次；多个 Web 标签页会各自通知。
- 快问可通过关闭按钮、Esc、外部点击和重复触发收起，挂载期间保留草稿与附件。待办仍保留在 Host，不同的新请求可以再次打开面板。桌宠声明根作用域列表插槽 `pet.panel.metrics`，传递面板可见性、焦点会话、任务状态，以及余额请求计数和接收 `PetBalanceReading`（已用比例与文案）的回调，由个人中心提供用量与余额并回应余额请求；桌宠不直接导入个人中心运行时代码。

- 快速提问依次执行 `session.create`（新会话时）、对每个拖入的文件执行 `fileUpload.upload`，再以 queue 模式执行 `session.prompt`。
- Desktop bridge（`window.dshDesktopPet`）在指针进入或离开角色与气泡时切换点击穿透，跟随 Host 可见性，并转发全局快捷键。
- 帧：来自 [`@deepseek-ai/dsh-pet/packs/whaletail-maid`](../../pet/pet/README.zh.md#pet-packs) 的内置包 `whaletail-maid@1.0.0`，idle、thinking、working、waiting、success、error 片段各取六帧，裁剪并缩放到 160 px。bundle 加载时用 `parsePetPack` 校验其 `pet.json`，帧以 data URL 形式内嵌。角色及其帧与媒体来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)；其素材仅限非商业使用，衍生作品须附上该地址（[条款](../../pet/pet/README.zh.md#pet-packs)）。设置页末尾的“角色来源”一行链接到内置 `pet.json` 的 `license.source` 地址。Host 通过 `pet.pack()`（`DSH_PET_DEV`）提供开发包时，Client 会再次校验并渲染它，角色下方显示"开发包"标记；无效或不完整的包会保留内置包。

</details>

<a id="model-experience"></a>
## 模型体验

无，本包在浏览器中渲染桌宠，不注册任何面向模型的内容。

#### KV Cache 影响

无；快速提问就是普通的用户提示。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **媒体支持** — 内置动作只使用透明 VP9 视频；生成图集已移除，相应动作等待 AI 视频片段补上；开发包仍使用帧图。尚无声音和说话状态，内置包只有上游三段悄悄话片段中的一段，余额读数只覆盖 DeepSeek 人民币钱包和 Codex 额度；桌面端移动仍需平台实测。
- **每个会话一个审批** — 会话状态只暴露优先级最高的待交互项，同一会话中并行的第二个审批需在主窗口回答。
- **重新显示入口** — 隐藏后 Web 页面角落留一个小鲸鱼按钮。Desktop 可以用全局快捷键、设置页，Windows 上还可以用托盘；macOS 暂无菜单栏入口。
